# 项目影像目录

精选工程现场、实验室装置和模型演示，用于理解系统组成及作业方式。视频统一移除音轨与非必要元数据；设备近景优先，原始长视频保留在本地。

首页优先展示约51秒的三维作业动画，便于先理解工作原理，再查看现场与实验室记录。
