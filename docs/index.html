六轴机械臂，加一轴升降

机械臂负责喷枪的空间指向，升降立柱扩展垂直作业范围。上位机结合热源信息与三维显示，协调机器人、分区阀和细水雾泵组。

项目覆盖异常热源感知、目标定位、运动控制、喷射联动与状态反馈，支持清洗、降温和灭火等运行模式。
