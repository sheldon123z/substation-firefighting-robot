# 试验与成果记录

江西项目的研究报告和功能验证报告提供了现场试验记录；惠州项目的2024年3月汇报提供了阶段测试及成果状态。下表保留试验对象和条件，便于理解照片、视频能支持哪些工程结论。

## 江西现场功能验证

试验覆盖泵组启动、机器人运动、清洗降温、单热源跟踪、多热源策略及消防联动等功能。[S1、S2](sources.md)

| 验证内容 | 记录结果 | 试验条件与含义 |
| --- | --- | --- |
| 模拟热源跟踪 | 误差在10厘米以内 | 主变停电，以约100℃热水模拟热源，检查随机位置识别与跟踪 |
| 喷射距离 | 有效距离15米，最大约20米 | 空喷试验，反映该配置下的喷射覆盖能力 |
| 泵组压力 | 平均工作压力11兆帕 | 两台高压泵参与该次现场验证，实测平均值与设定值一致 |
| 联动响应 | 约26秒 | 功能报告记录从消防信号到分区阀开启；其他段落另有至出水的描述，不据此拆分各环节耗时 |
| 作业模式 | 清洗、降温及模拟热源处置完成验证 | 检查运动、指向、供水和界面反馈之间的协同 |

这些记录证明系统在给定条件下完成了功能联动。热水模拟和空喷不等同于真实主变油火试验，也不应扩展为带电灭火验证。照片与视频主要展示运动、喷射和监测界面，定量指标以报告记录为依据。

## 惠州阶段测试与成果

以下均为截至2024年3月的阶段状态。[S4](sources.md)

| 内容 | 材料记载 | 展示时的范围 |
| --- | --- | --- |
| 红外识别 | 火灾识别“灵敏度”达到15秒 | 沿用阶段报告用语，作为识别时间指标展示，不称为识别准确率 |
| 机械臂测试 | 最大运动速度2米/秒 | 阶段测试指标，未给出可用于公开复现的完整工况 |
| 消防覆盖 | 关键部位覆盖率75% | 假定消防对象实验，不称为现场整站覆盖率 |
| 发明专利 | 3项已受理、4项已提交代理机构 | 申请推进状态，不称为7项授权 |
| 论文 | EI会议1篇可检索、中文期刊1篇录用 | 区分检索与录用状态 |

阶段材料将异常识别精度优化、避障可靠性提升、系统高度集成与样机安装列为后续工作，因此本仓库不将该汇报表述为最终验收证明。

## 阅读媒体的方法

优先查看机械臂与喷枪近景，再结合模拟热源跟踪和空喷片段理解执行过程。三维温度界面用于展示感知与可视化关联；结构图用于解释功能组成。不同项目的素材分别标注，研究方案、试验结果与个人贡献也分别说明。
