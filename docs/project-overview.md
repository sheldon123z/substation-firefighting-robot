# 变电站消防机器人项目概述

本项目面向主变压器火灾风险监测与定向处置，将热源感知、三维可视化、机器人运动控制和高压细水雾供水连接起来，形成从异常发现到执行机构联动的工程系统。本仓库以江西项目的现场功能验证为主体，同时介绍惠州项目后续开展的视觉识别与路径规划研究。

## 要解决的问题

主变压器外形复杂，固定喷头难以灵活调整喷射位置；局部异常升温又需要与背景热源区分。项目采用可移动喷枪配合温度监测，在保护对象周边定位异常热源、调整机械臂位姿，并在满足启动条件后协调供水。系统还提供清洗和降温模式，使同一套执行机构支持不同作业任务。[S1](sources.md)

## 江西工程系统

系统由五个功能部分组成。

| 部分 | 主要作用 |
| --- | --- |
| 感知单元 | 双光谱摄像机与感温探测器采集图像、温度及告警信息 |
| 模型与界面 | 将监测对象与三维模型关联，显示温度分布和设备状态 |
| 决策单元 | 识别目标区域，组织作业模式、热源跟踪和执行指令 |
| 运动机构 | 六轴机械臂配合一轴立柱升降，调整喷枪位置与指向 |
| 供水机构 | 泵组与分区阀联动，向末端喷枪供给高压细水雾 |

自动作业过程为“持续监测—异常定位—状态与启动条件判断—运动和供水联动—状态反馈”。多热源场景结合温度优先级与定点停留安排作业；具体启动阈值及现场布置不在公开展示中复现。江西系统已完成现场功能试验，详情见[验证记录](validation.md)。[S1、S2](sources.md)

## 惠州阶段研究

惠州项目在2024年3月阶段材料中记载了红外与深度视觉配准、异常区域三维恢复，以及机械臂运动学与避障轨迹研究。运动规划采用D-H参数建模和逆运动学求解，并结合人工势场、时间最优规划等方法探索无碰撞轨迹。上述研究属于惠州项目，不能反推为江西系统当时的实际实现。[S4](sources.md)

该阶段已形成技术方案并开展测试，机器人与细水雾系统的高度集成、样机安装仍列在下一步计划。两项工作的共通主线是把电力设备监测、机器人控制与消防执行连接成可验证的系统；个人承担的工作另见[个人贡献](contributions.md)。
